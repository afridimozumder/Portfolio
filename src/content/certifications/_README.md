# certifications collection

One Markdown file per certification or course. **Honesty rule:** `status` must be
truthful — never `earned` unless actually earned. Populated in Phase 2.
Field reference (see `src/content.config.ts`):

```md
---
name: "ISACA CRISC"
status: "planned"        # earned | course | in-progress | planned
provider: "ISACA"
progress: 0              # optional, 0–100 for in-progress items
note: "Strongest GRC signal — the direction the roadmap builds toward."
order: 1
---
```
